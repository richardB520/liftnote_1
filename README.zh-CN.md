# 练记 LiftNote

[English](README.md) · 中文

一个原生 iPhone 健身记录 App（SwiftUI）。核心思路：**不用固定 routine**，每次选今天练的部位，自动带出上次同部位的动作，边做边填；每组单独标记质量变化；每周看七个部位各练了多少组。

## 功能

**开始训练**
- 点「开始训练」，选部位（默认一个都不选，自己选）：胸、背、腿前侧、腿后侧、二头、三头、肩中束。
- 按每个部位**最近一次**的训练带出动作和组数（默认每个动作 2 组），重量、次数留空等你填，旁边显示**上次的重量 × 次数和质量**。点「上次 …」可以一键沿用；空着直接打勾，也会用上次的数据补上。
- 随时**换器械**（已经做完的组留在原器械下，没做的组换到新器械）、加动作、调整顺序、加热身组。
- 每一组都能编辑和删除（「⋯ → 删除这一组」）。空白组直接删，有数据的组先确认。没填完也能先保存。
- **放弃本次训练**：一组都没做也能退出，不留空记录。
- 训练标题自动生成，训练中加了别的部位的动作也会补进标题；手动改过的名称会保留。

**质量箭头 ↑ → ↓**
- 每组单独标：比上次好 ↑、一样 →、不如上次 ↓。点一下切换，长按选择或清除。
- 和「负重 / 次数变化」分开显示（比如 `+2.5kg`、`+1次`），质量变好不等于加重。

**器械库（147 个）**
- 诺德士 Nautilus、PRIME、Atlantis、Hammer Strength，以及自由重量 / 绳索。可以按品牌、插片 / 挂片 / 绳索、部位筛选，支持中文搜索，也可以加自定义器械。
- 不同品牌和型号的器械**分开保存历史**。
- **PRIME 挂片器械**：每组分别填 1、2、3 号挂片位挂了多少，基准选「每侧」或「共用」。挂片分配变了会显示「分配改变」，不会误判成加重。

**单手 / 双手**
- 所有背部动作，以及手臂、肩中束的绳索动作，可以切换「单手轮流 / 双手」。单手轮流时左右各做完算一组，次数填每侧。
- 单手和双手的历史分开保存，组间休息也分开设置。

**组间休息计时**
- 完成一组自动开始倒计时，显示在**这一组旁边**、训练页顶部，以及**锁屏和灵动岛**上（Live Activity），到点会发通知提醒。可以 −15 / +15 秒或跳过。
- 在「设置」里分别设置常规 / 双手和单手轮流的休息时间；每个动作也能单独设置（动作右上角「…」→「休息时间」）。

**语音记组**
- 点麦克风说，比如：「诺德士坐姿胸推，45 公斤，做了两组，第一组 10 次，第二组 8 次，都比上次轻松」。
- 中间可以停顿，接着说会接在后面，点「说完了」才整理。整理成一张可以修改的确认卡片。
- 能识别：器械和品牌、重量（公斤 / 磅）、组数、每组次数、质量（更好 / 一样 / 费劲，「都」作用于所有组，「这组」只作用于当前组），PRIME 挂片位（「每侧一号位 20、二号位 10、三号位没挂」），单手 / 双手。常见误识别会纠正（比如「上辈划船」→「上背划船」）。
- 没说器械名时记到当前动作（「第二组，40 公斤，9 次，比上次费劲」）。
- 器械有歧义时让你选；PRIME 没说「每侧 / 共用」时要你确认。
- 「保存 N 组」只记数据完整的组；「加入训练，稍后填写」会把没说完的组也放进训练列表，回去再填。

**每周组数**
- 人体正反面示意图 + 七个部位的进度条，目标默认 **10–20 组**（可改）。
- 只算已完成的工作组，热身不算；每组只计入动作**直接**训练的部位（胸推只算胸，不算三头）。
- 点部位能看到具体是哪几组；还有最近 6 周的对比表。周一为一周的开始，按手机当地时间计算。

**记录**
- 单次记录：表格形式，可以改训练名称、日期、备注，逐组编辑 / 删除 / 补记，**修改登记错的器械**（保留组、次数、质量；重量格式不同时提示重新填），删除动作或整次训练。也能补记一整次忘了记的训练。
- 连续对比：像训练笔记本一样，同一个器械的历次训练从左到右横向排开，对比重量、次数、质量。
- 所有修改都会同步到每周组数和下次训练的「上次」参考。

**数据**
- 只保存在手机本地，离线可用，进行中的训练随时保存，App 被关掉后能继续。
- 导出 / 导入备份（JSON）。导入是合并：只有备份里的版本更新时才覆盖，重复导入不会冲掉之后的修改。
- 不计算卡路里。

**WHOOP**：WHOOP 官方公开接口只能在授权后读取训练记录，不能让别的 App 远程开始或结束 WHOOP 的训练，所以目前没有做联动，设置页里会显示「未连接」。

## 装到 iPhone 上

需要一台装了 **Xcode 16 或更新版本** 的 Mac，iPhone 系统 **iOS 17 或更新**。普通 Apple 账号就能免费装。

1. 用数据线连接 iPhone 和 Mac，解锁手机，点「信任此电脑」。
2. Xcode → Settings → Accounts，登录 Apple 账号。
3. 双击打开 `LiftNote.xcodeproj`。
4. 左侧点最上面的 **LiftNote** 项目 → TARGETS 里分别选 **LiftNote** 和 **LiftNoteWidgetsExtension** → Signing & Capabilities → 勾选 Automatically manage signing，Team 选你的 Personal Team（两个都要选）。
5. 如果提示 bundle identifier 已被占用：点项目 → PROJECT「LiftNote」→ Build Settings → 搜索 `LIFTNOTE_BUNDLE_ID`，改成别的，比如 `com.你的名字.liftnote`（只改这一处，小组件和测试会跟着变）。
6. 顶部运行设备选你的 iPhone，点 ▶︎。
7. 第一次会提示开启开发者模式：手机「设置 → 隐私与安全性 → 开发者模式」打开并重启；然后「设置 → 通用 → VPN 与设备管理」里信任你的开发者账号，再点一次 ▶︎。
8. 第一次用语音时允许麦克风和语音识别；第一次休息计时时允许通知。

免费签名 7 天有效，到期后连上 Mac 再点一次 ▶︎ 即可（数据会保留）。也可以先在模拟器里看：运行设备选任意 iPhone 模拟器。

## 测试

核心逻辑（训练模板、每周统计、换器械、历史编辑、语音解析、停顿接续、备份合并）都有单元测试：

- Xcode 里按 **⌘U**；或者
- 在仓库根目录运行 `swift test`（核心逻辑单独成了一个 Swift Package）。

## 项目结构

```
LiftNote/
  Core/      数据模型、器械库、训练逻辑、每周统计、语音解析（只依赖 Foundation，可单独测试）
  App/       App 入口、数据保存、语音识别、通知和 Live Activity
  Views/     所有界面
  Shared/    App 和锁屏小组件共用的倒计时数据
LiftNoteWidgets/   锁屏 / 灵动岛倒计时
Tests/LiftNoteCoreTests/  单元测试
tools/gen_xcodeproj.py    新增 / 删除 .swift 文件后运行它重新生成 Xcode 项目
```

## 目前的限制

- 每次推送代码，GitHub Actions 都会在 Linux 和 macOS 上跑核心测试，并用 Xcode 编译整个 iPhone App 和锁屏小组件（模拟器目标）。真机上的语音识别、锁屏倒计时还需要你在手机上实际试用。
- 器械库里的系列 / 型号名称是常见叫法，不一定和你健身房的铭牌完全一致，可以用自定义器械补充。
- 中文语音识别的效果取决于手机和网络环境，确认卡片里都可以手动改。
